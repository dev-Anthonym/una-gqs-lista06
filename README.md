# Projeto 002 — Cálculo de uma Equação do 2º Grau

## 📌 Descrição

Este programa em Java calcula o valor do **Delta (Δ)** e as raízes **X1** e **X2** de uma equação do segundo grau utilizando a fórmula de Bhaskara.

A equação utilizada é:

**ax² + bx + c = 0**

Onde:

- `a` = coeficiente de x²
- `b` = coeficiente de x
- `c` = termo independente

---

## 🎯 Objetivo

O objetivo do algoritmo é:

1. Solicitar ao usuário os valores de `a`, `b` e `c`.
2. Calcular o valor de Delta.
3. Calcular as raízes `X1` e `X2`.
4. Exibir os resultados na tela.
